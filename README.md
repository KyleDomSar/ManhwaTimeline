# ManhwaTimeline

A React Native + Expo app for discovering and tracking manhwa.

## Stack

- Expo
- React Native
- TypeScript
- React Navigation
- MangaDex API

## Development

Install dependencies:

```bash
npm install
```

Start Expo:

```bash
npx expo start
```

Run the TypeScript check:

```bash
npm run typecheck
```

## Current status

The project starts from a clean foundation with:

- Dark UI theme
- Bottom tab navigation
- MangaDex API integration
- Discover screen using live popular manga data
- Reusable manga card
- Library and Settings placeholders

Next work will add search, manga details, tracking, reading status, local persistence, and a more complete UI.
